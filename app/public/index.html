    Recovery demo

    Practice restoring a saved snapshot of this notebook.

    1. Save the notes you want to keep in Folio.
    2. From the project root, create a backup: ./scripts/backup.sh
    3. Edit or delete a note, then list available snapshots: ./scripts/list-backups.sh
    4. Restore the key you chose: ./scripts/restore.sh KEY
    5. Refresh this page to load the restored notes.

    Restoring replaces the entire database with the chosen snapshot. Changes made after that backup are lost.

    Backup and restore commands run in a terminal; this dialog does not trigger them.
